About This Visualization

Research Question

How do nutritional characteristics relate to consumer ratings of breakfast cereals? This visualization explores whether healthier cereals (higher fiber, lower sugar) receive better ratings, or if taste preferences (potentially correlated with sugar content) dominate consumer preferences.

Design Rationale

Visual Encodings:

  • Scatter Plot: Chosen to reveal correlations between nutritional variables and ratings. The two-dimensional layout allows users to explore relationships between any pair of variables.
  • Color: Encodes manufacturer, allowing users to identify brand-specific patterns. Distinct colors were chosen for visual differentiation.
  • Size: Encodes a third variable (default: calories), providing additional information density without cluttering the visualization.
  • Tooltips: Provide details-on-demand, showing complete nutritional information on hover without overwhelming the main view.

Interaction Techniques:

  • Dynamic Axis Selection: Enables exploration across seven nutritional dimensions, allowing users to discover unexpected correlations.
  • Manufacturer Filtering: Supports comparative analysis of specific brands.
  • Hover Highlighting: Emphasizes individual data points for detailed inspection.
  • Smooth Transitions: Animated transitions between different views help users maintain context when switching variables.

Alternatives Considered: We initially considered a parallel coordinates plot but found it less intuitive for revealing bivariate relationships. A bar chart was too limiting for exploring multiple dimensions simultaneously.

Data Source

Dataset: 80 Cereals Dataset (Kaggle)
Contains nutritional information and consumer ratings for 77 breakfast cereals.

Development Process

Team Structure: Solo project

Time Investment: Approximately 12-15 hours total

  • Data exploration and question formulation: 2 hours
  • Initial design sketches and prototyping: 2 hours
  • D3.js implementation (scatter plot, axes, scales): 4 hours
  • Interactive features (dropdowns, filtering, transitions): 3 hours
  • Styling, tooltips, and polish: 2 hours
  • Testing, debugging, and write-up: 2 hours

Most Time-Consuming Aspects: Implementing smooth transitions between different axis configurations while maintaining data binding took considerable effort. Ensuring tooltip positioning worked correctly at all viewport sizes also required significant iteration.

Technologies Used

  • D3.js v7 - Data visualization library
  • HTML5, CSS3, JavaScript (ES6)
  • GitLab Pages - Web hosting
